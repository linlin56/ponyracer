# Pony Racer
This is a school project made in Angular. It displays a horse race. You can bet on horses and click on them to give them a boost.
This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 21.2.0.

## Usage
- `npm i`
- `ng serve`
- Open `localhost:4200` in your browser.
- Create an account or login
- Bet on a pony
