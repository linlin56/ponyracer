# Dossier des images de poneys

Placez ici vos fichiers GIF pour les poneys. Les fichiers doivent être nommés selon la couleur de l'API :

- `pony_blue.gif`
- `pony_green.gif`
- `pony_orange.gif`
- `pony_yellow.gif`
- `pony_purple.gif`

Ces couleurs correspondent aux valeurs renvoyées par l'API PonyRacer (en minuscules).

En attendant, une image placeholder est affichée automatiquement si le fichier n'est pas trouvé.
